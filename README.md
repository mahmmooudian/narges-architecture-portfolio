# Narges Salmanzadeh — Architecture Portfolio

A responsive, multi-page architecture portfolio built from the supplied résumé.

## Pages
- `index.html` — Home
- `projects.html` — project overview with filters
- `project-complex.html` — architectural complex (image gallery)
- `project-interior.html` — interior visualization (image gallery)
- `project-exterior.html` — exterior perspectives (image gallery)
- `about.html` — experience, education and skills
- `contact.html` — contact page; email application form

## Run locally
Open `index.html` in your browser, or use a local server:

```bash
python -m http.server 8000
```

Visit `http://localhost:8000`.

## Publish to GitHub Pages
Upload the contents of this folder (including `index.html` and `assets/`) to the root of your GitHub Pages repository, then enable **Settings → Pages → Deploy from a branch**.

## Features
- Responsive editorial visual system
- English/Persian toggle (stored in localStorage)
- Project category filters
- Accessible gallery lightbox (previous/next, Escape, keyboard arrows)
- Contact form that opens the visitor's mail client (no backend)
- Downloadable original CV
- Local WebP assets for fast performance

## Image provenance
All architectural imagery in `assets/images` was generated with AI and cropped to create conceptual portfolio illustrations. They **do not represent documented or built projects**. Illustrative BIM/plan visuals likewise do not represent issued drawings. The project headings, academic background and work experience are based on the provided résumé; no external client/project history has been invented.
